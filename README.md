# Видеорегистратор

Программа для Ubuntu: камеры и архив регистраторов Hikvision/HiWatch. Замена iVMS-4200 для просмотра и скачивания.

## Установка

Скачайте пакет последней версии со страницы релизов и установите его:

```
cd /tmp && wget -O nvrview.deb https://github.com/dotsbik/nvr-viewer/releases/latest/download/nvrview_all.deb && sudo apt install ./nvrview.deb
```

apt сам поставит всё нужное: GTK, GStreamer, ffmpeg. Программа появится в меню как «Видеорегистратор», из терминала она запускается командой `nvrview`.
Обновление: та же команда. Удаление: `sudo apt remove nvrview`.

Подходит для Ubuntu 22.04 и 24.04.

## Первый запуск

1. Меню (☰) → «Регистраторы…» → «Добавить». Укажите название, адрес и порты: веб 80, видео 554.
   Кнопка «Проверить связь» не тратит попытки входа: она не отправляет ни логин, ни пароль.
2. Войдите своей учётной записью регистратора. Права (какие камеры, архив, скачивание) задаются на самом регистраторе.
3. Галочка «Запомнить пароль» сохраняет пароль в брелоке паролей Ubuntu. Без неё пароль спрашивается при каждом запуске.

Для каждого сотрудника лучше завести на регистраторе отдельного пользователя с нужными правами, а не давать admin.

## Работа

* **Онлайн.** Сетка 1/4/9/16 со страницами. Двойной щелчок открывает камеру крупно в основном потоке, там же есть кнопка «Снимок». Правый щелчок по камере открывает меню: крупно, снимок, архив этой камеры. F11 включает полный экран.
* **Архив.** Выберите камеру и день: стрелками или щелчком по дате (в календаре дни с записями выделены жирным). Щелчок по шкале запускает просмотр с этого времени, колесо мыши меняет масштаб шкалы.
  * Обычная скорость (1×): видео идёт потоком прямо с регистратора и начинается за пару секунд. Скачивать запись и иметь право на скачивание для этого не нужно.
  * Ускорение 2×/4×/8×: регистратор не ускоряет поток, поэтому запись сначала скачивается. Это может занять время: записи бывают по 1 ГБ.
  * Кнопки «±30 с» перематывают на 30 секунд назад или вперёд.
  * Скачать: выделите записи (или задайте «С … по …» и нажмите «Выделить»), затем «Скачать выбранное». Видео сохраняется в MP4, папка указана под кнопкой.

## Безопасность

* Программа только читает данные регистратора. Запросы на изменение запрещены в самом коде (белый список).
* Пароль передаётся только через Digest. Если регистратор предлагает Basic по HTTP, пароль не отправляется.
* После неверного пароля запросы останавливаются сразу. После 3 неудачных входов вход закрывается на 30 минут, чтобы регистратор не заблокировал компьютер.
* HTTPS (если включён на регистраторе): сертификат запоминается при первом входе, а при подмене соединение останавливается.
* Пароля нет в файлах настроек, журнале, адресах потоков и командных строках.
* Настройки, журнал и кэш доступны только владельцу учётной записи Ubuntu:
  * настройки в `~/.config/nvrview`;
  * журнал в `~/.local/state/nvrview`;
  * кэш в `~/.cache/nvrview`, он хранится 3 дня и не больше 5 ГБ.

## Для разработчика

```
make test   # тесты на поддельном регистраторе (реальный не нужен)
make run    # запуск из исходников
make deb    # тесты + сборка dist/nvrview_<версия>_all.deb
```
